In this project, we are using Firecrawl which provides software for crawling, scraping and searching websites along with langgraph, langchain, and OpenAi
* Firecrawl 
    * Api Keys -> https://www.firecrawl.dev/app/api-keys
    * Docs: https://docs.firecrawl.dev/features/search

* OpenAI Developer
    * Usage -> https://platform.openai.com/usage

To use uv, install uv on linux using `curl -LsSf https://astral.sh/uv/install.sh | sh` (latest method to install at the time of initiating this project).
To use the venv use uv venv first to install all the dependencies, and then source .venv/bin/activate to activate it. Then use uv sync to install all the dependencies present in the toml file
